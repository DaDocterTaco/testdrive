Target length: roughly 110 seconds. This is a recording plan; no video has been recorded by the presence of this file. Use the actual deployed release and actual hardware. If a segment does not work, omit its claim and record the limitation.

## Recording notes

- Speak only to behavior visible in the actual release. Do not narrate future features as current.
- Label synthetic fixture data on screen. Do not present a simulated defect as a real hardware failure.
- Use a physical phone for the phone claim. If only responsive emulation is available, say “mobile layout” and disclose it.
- Hide private notifications, system usernames, serials, raw report text, local paths, and credentials.
- Leave camera/microphone tests and verify capture indicators turn off before finishing.
- End with actual links. Check video permissions in a logged-out window before submission.
